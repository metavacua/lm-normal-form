## Purpose

For a fact a (a prompt and a target token) the margin m_a(σ) is the logit of the target minus the largest other
logit; the model is sound for a when m_a > 0. Soundness for a set of facts is one strict inequality per fact over the
same weights. The weights that appear in m_a are the path of a, and the algebraic expression of m_a through them can
be differentiated exactly. This batch examines that algebra and uses it to choose substitute weights at three
granularities:

1. **Element-wise**: one weight, one fact. The margin is a function of one number.
2. **Sequent-wise**: one fact (one input, one output), the set S of weights on its path.
3. **Graph-wise**: several facts whose paths intersect; shared weights carry the constraints of every fact through
   them, and the facts the model currently gets right enter as constraints to preserve.

## The algebra, for the exact cases

Let x be the residual at the last position after the last layer, n = x / √(mean(x²) + ε_n) its normalisation, g the
final-norm gain, E the tied embedding (also the head), z = E (g ⊙ n) the logits, and a the last position's
feed-forward activation vector before the last layer's down projection. Three kinds of weight enter the logits
without passing through any further nonlinearity beyond the final norm, so the margin as a function of that weight
is exact in closed form:

- the final-norm gain g_i: z′ = z + (g′_i − g_i) n_i E[:, i], affine in g_i;
- a head-row entry E[v, i] (output side; exact when token v is not in the prompt): only z_v changes,
  z′_v = z_v + (E′[v, i] − E[v, i]) g_i n_i, affine in the entry;
- a last-layer down-projection entry W[i, j]: x′ = x + (W′_ij − W_ij) a_j e_i, then z′ = E (g ⊙ rms(x′)), a ratio of an
  affine function and the square root of a quadratic in W′_ij.

For these the margin is evaluated at every finite bf16 value of the weight (65,280 values), so the feasible set
{w′ : m_a(w′) ≥ ε} is computed exactly and not estimated. For every other weight the margin is a composition through
attention, SiLU and normalisations; it is evaluated on a 513-point grid by full forward passes and its derivative is
exact by autograd.

## Cells

- **00 Gate.** The 189 margins before any change; the count of positive margins must equal batch 0004's 22.
- **01 The path of France (the base model).** The exact gradient of France's margin with respect to every weight.
  The path size (weights with non-zero gradient), the concentration of first-order attribution |g·w| by tensor
  sort and by layer, the top coordinates. Finite-difference check of the gradient on 12 weights (4 per exact kind).
- **02 Element-wise.** The 10 largest-|g| weights of each exact kind (30) enumerated over all finite bf16 values,
  the 20 largest-|g| weights of any other kind on the grid. Per weight: the feasible set for ε = 0.5 (intervals, whether the
  current value lies in it, the nearest feasible value). The nearest feasible substitute is applied alone and the
  effect on all 189 facts is measured. The enumeration is checked against full forward passes at the current value
  and at 3 other values per weight.
- **03 Sequent-wise (France).** Support S = the 30,000 largest-|g| coordinates. (a) minimum L2 change:
  Δ = (ε − m)·g / ‖g‖², repeated with the gradient re-taken at the rounded weights (Newton), up to 8 rounds.
  (b) minimum L1 change with a box |Δ_i| ≤ max(0.25|w_i|, 0.01): a fractional knapsack, solved exactly by taking
  coordinates in decreasing |g_i|. Reported: rounds to reach margin ≥ ε, the number of weights whose bf16 value
  changed, ‖Δ‖₂, ‖Δ‖₁, ‖Δ‖₂/‖w_S‖₂, the effect on the other 188 facts, the effect on bits per token over a fixed
  English sample (SmolLM2's tokenizer, 4,096 tokens).
- **04 Graph-wise.** Support S = the 30,000 largest max-over-constraint-facts |g| coordinates. A linear program
  (HiGHS) per round: minimise ‖Δ‖₁ + 100·Σ slack subject to, for every install fact, m + JΔ + slack ≥ ε; for every
  currently-correct fact outside the install set, m + JΔ + slack ≥ min(ε, m); the box |Δ_i| ≤ trust·max(0.25|w_i|, 0.01);
  J the exact Jacobian at the current rounded weights. Slack above 1e-6 names a fact in conflict. Up to 6 rounds, the
  trust factor 1, 1, 0.5, 0.5, 0.25, 0.25, re-linearised each round, stopped when every install fact is correct.
  Runs: **G11** (install the 11 of the twelve countries of batches 0030 to 0032 that the authority labels; preserve
  the currently correct facts outside them), **G189** (install every currently wrong fact; preserve the currently
  correct ones), **G11perm** (install a cyclic shift of the 11 targets; same preserve set).
- **Controls.** (a) G11perm against G11. (b) The gradient finite-difference check. (c) A random change with the
  same support and the same L2 norm as France's sequent-wise substitute.

## Predictions, with severity

- **T1, high (instrument).** The count in cell 00 is 22; the autograd gradient agrees with the central finite
  difference to within 5 % on all 12 checked weights.
- **T2, high (instrument).** The exact enumeration reproduces the base margin at the current value to 1e-3 and the
  full-forward margin at 3 other values to 1e-3, for every enumerated weight.
- **T3, moderate.** France's margin is negative at the start (the token ` the` beats ` Paris`), and for at least 5
  of the 30 exactly enumerated weights some bf16 value makes France's margin at least 0.5 (a single weight can flip
  France in the model's own number format).
- **T4, moderate.** The sequent-wise L2 substitute reaches margin ≥ 0.5 within 8 rounds with ‖Δ‖₂/‖w_S‖₂ < 0.05; it
  changes the soundness count on the other 188 facts by at most 3 and the bits per token by less than 0.01.
- **T5, moderate.** The knapsack substitute reaches margin ≥ 0.5 changing at most 200 weights.
- **T6, moderate.** G11 is feasible without slack in every round, installs all 11 within 6 rounds, preserves at
  least 17 of the 18 currently-correct facts outside the install set, changes fewer than 10,000 weights, and the
  count over all 189 rises from 22 to at least 40.
- **T7, low.** G189 ends with at least 150 of 189 correct and with bits per token increased by more than 0.05
  against the unchanged model.
- **T8, moderate (control).** G11perm needs a final ‖Δ‖₁ at least twice G11's. Refuted if the permuted install is no
  more expensive than the genuine one; then the solver is a generic memoriser and the claim that the facts are
  nearly installed already is false.
- **T9, high (control).** A random change with the support and norm of France's L2 substitute changes France's
  margin by less than 25 % of what the substitute does.

## Observed, no prediction

The attribution concentration (the share of Σ|g·w| in the top 0.1 %, 1 % and 10 % of weights), by tensor sort and
layer; the solved weights' tensor sorts and layers for G11 and G189 against batch 0032's finding that thinning layer
12's feed-forward gave 94; the facts that need slack in G189; the per-round trajectory; the time and memory per cell.

deletions; any claim that a substitute generalises beyond the facts it was solved for, other than the measured
effect on the 189 facts and the English sample.
