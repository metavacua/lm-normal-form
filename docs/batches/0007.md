# Batch 0007: which parts of a model tolerate which map

- **Registered:** 2026-10-06, before any cell ran.
- **Kind:** a test, of H-S.
- **Status:** not yet run.
- **Branch:** `batch/0007-selective`, on top of batch 0006.
  **Workflow:** `.github/workflows/batch-0007.yml`.
  **Depends on:** batch 0004's authority query, prompt derivation and
  judge; batch 0005's quantization cell and its finding that llama.cpp's
  per-class overrides apply only under a quantized file type; batch 0005's
  baselines for Qwen3-1.7B (float16 and Q8_0 on all linear weights keep
  every judged count; Q4_0 everywhere loses 53 canonical answers; TQ2_0 on
  the embedding table alone destroys the fragment).

## Hypothesis

**H-S** (`docs/research/questions.md`): for a model and a fragment of an
authority, the tensors partition into parts that carry the fragment's
soundness and parts that do not; maps chosen per part keep the judged
counts within a stated tolerance while size falls; which parts tolerate
which maps is a measurable property of the model, not a preset.

Transformation T is **soundness-preserving on the fragment at tolerance
ε** when, over the 189 determined countries, Δcanonical ≥ −ε, Δglut ≤ 0
and Δcollapse ≤ 0, each against the float16 baseline of the same model.
The maps here are llama.cpp's own: Q8_0, Q4_0, TQ2_0, applied by
`llama-quantize` to one class of tensors with every other tensor left at
float16. The classes: the token embedding and output table (tied in
Qwen3-1.7B), attention query and key, attention value and output, FFN up
and gate, FFN down. Norms stay float32 throughout.

## Derived predictions

- **P1.** The embedding class is the most sensitive at every map: Q4_0 on
  it alone costs more canonical answers than Q4_0 on any other single
  class.
- **P2.** At least one class tolerates Q4_0 at ε = 0, and at least one
  class tolerates it at ε ≤ 2.
- **P3.** No class of this float model tolerates TQ2_0 at ε ≤ 10: the model
  was not trained under a ternary constraint, so there is no ternary
  structure for the map to preserve (contrast TriLM in batch 0005).
- **P4.** Of the three compositions chosen before the table was known,
  "Q4_0 on everything but the embedding" keeps more canonical answers than
  Q4_0 everywhere (0005: 92), and the composition that keeps the FFN at
  Q8_0 keeps more than the one that keeps attention at Q8_0, because the
  relation is stored in the FFN.

## What refutes what

- A class other than the embedding costing more under Q4_0 refutes P1 for
  this model.
- Every single-class Q4_0 variant costing more than 2 canonical answers
  refutes P2 and, with it, H-S's claim at ε = 0 for Q4_0 on this model and
  fragment (H-S could still hold at other maps and tolerances; that is a
  weaker H-S, and the batch says so).
- Any class holding TQ2_0 within ε ≤ 10 refutes P3 and is a finding about
  where the fragment is not.
- The compositions failing P4 says the fragment's soundness is in
  attention as much as in the FFN for this model, which contradicts the
  key-value reading of the FFN that P4 rests on.

## Cells

Twelve, all Qwen3-1.7B, converted to float16 GGUF by llama.cpp's
converter, quantized by `llama-quantize` (file type = the map, every other
class overridden to f16), tensor types recorded from the file, read on
batch 0004's 1,725 prompts, judged by batch 0004's judge:

- 01–05 Q4_0 on: embedding and output; q and k; v and output; up and gate;
  down.
- 06–09 TQ2_0 on: q and k; v and output; up and gate; down. (TQ2_0 on the
  embedding, and on all attention or all FFN, are batch 0005's second run.)
- 10 Q4_0 on everything but the embedding. 11 Q4_0 attention with Q8_0
  FFN. 12 Q8_0 attention with Q4_0 FFN.

Each cell records the model revision, the quantizer's time and memory, the
server's peak memory from `/proc`, the file sizes, and writes its counts as
step outputs. Baselines: float16 (0005 second run's per-class cells of the
first run, count for count equal to float32), Q8_0 all (145 / 1 / 2 / 41),
Q4_0 all (92 / 0 / 2 / 95), TQ2_0 all (0).
