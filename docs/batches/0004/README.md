# Batch 0004: the judge's tables

The judge's output for the first run (judge run 37414377859 over run
37411731358), as the Oxigraph CLI wrote it: TSV with typed literals.
`countries.json` is the authority as derived from Wikidata's answer fetched
at the time in `fetched-at.txt`. `soundness.second-run.tsv` is the same
table from the second run (37414639168); every integer in it equals the
first run's. `top1.tsv.gz` lists every first-ranked answer of every model.

These are data, kept because the run's artifacts expire after a day. The
answer files themselves (12 × 1 MB) are not kept here.
